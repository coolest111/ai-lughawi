# مدقّق | AI

نموذج أولي لتطبيق تدقيق لغوي مدعوم بواجهة Streamlit وواجهة OpenAI API.

## التشغيل
1. ثبّت Python 3.10 أو أحدث.
2. افتح الطرفية داخل مجلد المشروع.
3. نفّذ:
   ```bash
   pip install -r requirements.txt
   streamlit run app.py
   ```
4. أدخل مفتاح OpenAI API داخل التطبيق عند تشغيله.

## المزايا
- تصحيح إملائي ونحوي وصرفي.
- مراجعة علامات الترقيم والأسلوب.
- شرح أسباب التصحيحات عند تفعيل الخيار.
- اقتراح بدائل لغوية.
- خيارات للنصوص الأكاديمية والمترجمة.
- تنزيل النص المصحح كملف TXT.

## ملاحظات
- هذا نموذج أولي؛ يتطلب اتصالًا بالإنترنت ومفتاح API صالحًا وقد تُحتسب رسوم استخدام وفق حساب API.
- لا تضع مفتاح API داخل الكود أو تشاركه.
- راجع النتائج يدويًا قبل اعتماد النص النهائي.
